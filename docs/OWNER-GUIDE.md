# MayoTechX — owner guide (v8)

## Architecture
Static site on GitHub Pages (no server, no database, nothing to pay). Pages are generated by the build
scripts; marketplace data is loaded in the browser from `/data/*.csv`.

| Feature | How it works |
|---|---|
| Publisher Marketplace | `/marketplace.html` + `assets/js/market.js` reading `data/publishers.csv` |
| Directories | `/directories.html` reading `data/directories.csv` |
| Smart Site Finder | `/smart-finder.html` — heuristic score (topic 35, country 15, language 15, budget 15, authority 10, availability 5, freshness 5) |
| Shortlist & quote | stored in the visitor's browser; request is sent by WhatsApp or email (nothing charged) |
| Forms | WhatsApp or email hand-off, consent checkbox, honeypot spam trap. No server storage. |
| AI assistant | retrieval over approved site content (`assets/js/kb-*.js`), WhatsApp hand-off. No paid API. |
| Analytics events | `dataLayer`/`gtag` events fire only if you add GA4/GTM (add consent banner first) |

## Everyday edits
- Contacts and social links: `assets/js/data.js`
- Publishers / directories: `data/*.csv` (see `data/README.md`)
- Real completed orders ticker: `ORDERS` in `assets/js/data.js`

## Rollback
- Branch `backup-v7` holds the previous live version.
- To roll back: GitHub → Settings → Pages → choose branch `backup-v7`, or revert the v8 commit on `main`.
